Review

Two equivalent ways of representing the g-formula…

\[\mathbb{E}[Y^a] = \mathbb{E}\Big[\mathbb{E}[Y \mid A=a, L]\Big] = \mathbb{E}\Big[Y \frac{I(A=a)}{P(A=a \mid L)}\Big]\].

Review

Motivating two different ways of leveraging parametric models:

  • \(logit(P(Y=1 \mid A=a, L=l)) = \theta_0 + \theta_1a + \theta_2l+\theta_3al\)
  • \(logit(P(A=1 \mid L=l)) = \eta_0 + \eta_1l\)
  • \[\begin{align} & \mathbb{E}[Y^{a=1}] \\ = & \mathbb{E}\Big[expit(\theta_0 + \theta_1 + \theta_2L+\theta_3L)\Big] \\ = &\mathbb{E}\Big[Y \frac{I(A=1)}{expit(\eta_0 + \eta_1L)}\Big]\end{align}\]

Review

Motivating two different types of estimators:

  • \(\frac{1}{n}\sum\limits_{i=1}^n expit(\hat\theta_0 + \hat\theta_1(a=1) + \hat\theta_2L+\hat\theta_3(a=1)L_i) \to \mathbb{E}[Y^{a=1}]\)
  • \(\frac{1}{n}\sum\limits_{i=1}^n\frac{I(A_i=a=1)}{expit(\hat\eta_0 + \hat\eta_1L_i)} \to \mathbb{E}[Y^{a=1}]\)
  • Remember, consistency of our estimators depends on modelling assumptions.
  • Discussion question: if you were forced to specify a model for treatment or for the outcome, which would you choose, and why?

IPW clarifies why we need positivity:

\[ \mathbb{E}\Big[Y \frac{I(A=a)}{P(A=a \mid L)}\Big]\]

What happens if \(P(A=a \mid L) = 0\)?

More IPW intuition

\[\begin{align*} \mathbb{E}\Big[Y^{a}\Big] = \mathbb{E}\Big[Y\frac{I(A=a)}{f(A \mid L)}\Big] \end{align*}\]

Radon-Nikodym theorem for a change in measure: Let \(P^*\) be some arbitrary law that is different from \(P\). According to the Radon-Nykodym theorem we have:

\[\mathbb{E}_{\color{red}{P^*}}[Y] = \mathbb{E}_{\color{blue}{P}}\Big[Y \frac{\color{red}{f_{P^*}(Y, A, L)}}{\color{blue}{f_{P}(Y, A, L)}}\Big].\]

We want to change from the factual law to the counterfactual law of \(Y\).

More IPW intuition

\[\mathbb{E}[Y^a] \equiv \mathbb{E}_{\color{red}{P^*}}[Y] = \mathbb{E}_{\color{blue}{P}}\Big[Y \frac{\color{red}{f_{P^*}(Y, A, L)}}{\color{blue}{f_{P}(Y, A, L)}}\Big].\]

More IPW intuition

Let \(A^{a}\) denote the variable for the under an regime that fixes treatment to \(a\).

\[\begin{align}\color{red}{f_{P^*}(y, a', l) = P(Y^{a}=y \mid A^a=a', L^a=l) P(A^a=a' \mid L^a=l) P(L^a=l)}\end{align}\]

\[=\color{blue}{P(Y=y \mid A=a', L=l)} \color{red}{P(A^a=a' \mid L^a=l)} \color{blue}{P(L=l)}\]

More IPW intuition

Discussion Question: What is \(\color{red}{P(A^{a}=a' \mid L^a=l)}\)?

We have \[\color{red}{P(A^{a}=a' \mid L^a=l) = I(a'=a)},\] i.e., all the probability mass is on the value \(a\).

\[\color{red}{f_{P^*}(y, a', l)} = \color{blue}{P(Y=y \mid A=a', L=l)} \color{red}{I(a'=a)} \color{blue}{P(L=l)} \]

\[\color{blue}{f_{P}(y, a', l) = P(Y=y \mid A=a', L=l) f(a' \mid l) P(L=l)}\]

More IPW intuition

So:

\[\begin{align*} \frac{\color{red}{f_{P^*}(y, a', l)}}{\color{blue}{f_{P}(y, a', l)}} & = \frac{\color{blue}{P(Y=y \mid A=a', L=l)} \color{red}{I(a'=a)} \color{blue}{P(L=l)}}{\color{blue}{P(Y=y \mid A=a', L=l) f_P(a' \mid l) P(L=l)}} \\ & = \frac{ \color{red}{I(a'=a)}}{\color{blue}{f_P(a' \mid l)}} \end{align*}\]

More IPW intuition

\[\begin{align*} \mathbb{E}_{\color{red}{P^*}}[Y] = & \mathbb{E}_{\color{blue}{P}}\Big[Y \frac{\color{red}{f_{P^*}(Y, A, L)}}{\color{blue}{f_{P}(Y, A, L)}}\Big] \\ = & \mathbb{E}_{\color{blue}{P}}\Big[Y \frac{\color{red}{I(A=a)}}{\color{blue}{f_P(A \mid L)}}\Big] \end{align*}\]

Other Propensity-based methods

A classical result: suppose consistency, positivity hold. Define \[\pi(L) = P(A=1 \mid L).\] If \[Y^a \perp A \mid L\] then

\[Y^a \perp A \mid \pi(L).\] Implications: we can match, condition, stratify on the propensity score.

Propensity matching

Consider the following procedure:

  • For every treated individual (\(A=1\)) find an untreated individual (\(A=0\)) with the same\(^*\) propensity \(\pi(L)\). Suppose there exists a match for all individuals with (\(A=1\)). Let \(\mathcal{B}_n\) denote the set of indices for individuals in the original sample, for whom a match is found.
  • Consider the following estimator:
    • \(\frac{\sum\limits_{i\in\mathcal{B}_n}I(A_i=1)Y_i}{\sum\limits_{i\in\mathcal{B}_n}I(A_i=1)} - \frac{\sum\limits_{i\in\mathcal{B}_n}I(A_i=0)Y_i}{\sum\limits_{i\in\mathcal{B}_n}I(A_i=0)}.\)
    • Is this estimator consistent for some causal effect?
    • Is it the marginal ATE? If not, what kind of ATE is it?

Propensity matching

Matching the treated individuals targets the Average treatment effect among the treated (ATT)

\[\mathbb{E}[Y^{a=1} \mid A=1] - \mathbb{E}[Y^{a=0} \mid A=1].\]

  • Discussion Question: How do we interpret this?
    • How might this effect be useful in practice?
  • The ATT requires weaker assumptions than the ATE to identify.
    • Discussion Question: Why?

Propensity matching

The ATT requires fewer assumptions because, under consistency, we identify \(\mathbb{E}[Y^{a=1} \mid A=1]\) for free.

  • Partial exchangeability: \(Y^{a=0} \perp A \mid L\)
  • Partial positivity: \(P(A=0 \mid L=l)>0\) for all \(l\) with positive probability in the subpopulation with \(A=1\).

Propensity matching

expit <- function(x) exp(x) / (1 + exp(x))
n <- 10000
beta <- c(-1, 1, 0.5)

U_L  <- runif(n)
U_A  <- runif(n)
U_Y1 <- runif(n)
U_Y0 <- runif(n)

S <- rbinom(n, 1, 0.7)             
L <- ifelse(S == 1,
            qnorm(U_L,  1, 0.75),    
            qnorm(U_L, -3, 0.5))   

eta <- c(-2, 1)                    
pi  <- ifelse(L < -1, 0, expit(eta[1] + eta[2]*L))
A   <- rbinom(n, 1, pi)

Y1 <- qnorm(U_Y1, beta[1] + beta[2]*1 + beta[3]*L, 1)
Y0 <- qnorm(U_Y0, beta[1] + beta[2]*0 + beta[3]*L, 1)
Y  <- Y1*A + Y0*(1-A)

df2 <- data.frame(L=L, A=A, pi=pi, Y1=Y1, Y0=Y0, Y=Y, S=S)

Propensity-score methods summary

  • All methods require the same three usual assumptions.
  • Propensity-score regression methods
    • When we are able to correctly specify the outcome model, we identify causal effects, but…
      • simple models rarely identify causal effects (residual confounding from model misspecification)
      • complex models complicate interpretation (conditional effects) and estimation (curse of dimensionality)

Propensity-score methods summary

  • Propensity matching methods
    • Require weaker positivity and exchangeability assumptions but…
      • different matching strategies lead to different estimands with different interpretations
      • perfect matches (almost) never exist when \(L\) is continuous, so must specify a matching method.
